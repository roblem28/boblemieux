EMBERWATCH is a live fire map built on free public data — NASA FIRMS VIIRS satellite hotspots, NIFC incidents and perimeters, and NWS warnings and evacuation alerts, all on a keyless Esri dark basemap. Toggle satellite imagery, filter by confidence and age, share a view by URL, and save places you care about. A built-in SITREP assistant summarizes what's burning near any point. Built with MapLibre GL JS and a single Netlify function proxying the FIRMS API, so no key ever ships to the browser.
